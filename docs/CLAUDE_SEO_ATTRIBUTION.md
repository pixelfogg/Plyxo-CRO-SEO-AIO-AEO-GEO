# Claude-SEO Architectural Inspiration & Attribution

Plyxo incorporates core architectural concepts and deep technical SEO heuristics inspired by the pioneering work in [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo).

### Key Architectural Heuristics Adapted:
- **Comprehensive Technical SEO Auditing**: In-depth analysis of crawl budget, status code graphs, schema markup, and canonical integrity.
- **E-E-A-T & Entity Optimization**: Algorithmic evaluation of content author transparency, editorial integrity, and Knowledge Graph topic density.
- **Actionable Remediation Over Scoring**: Providing ready-to-use TypeScript, JSX, and HTML code patches rather than abstract numeric scores.

We express our gratitude to the open-source community and [Daniel Agrici](https://github.com/AgriciDaniel) for establishing foundational standards in autonomous AI SEO workflows.
